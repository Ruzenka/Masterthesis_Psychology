This folder contains the datasets used in a master's thesis titled Altruism and parochialism in meat-consumption profiles: Conflict intensity and identification with dietary and mammalian ingroup.

## Files

- [**data_raw.xlsx**](data_raw.xlsx) – Raw survey data exported from SoSci Survey.
- [**data_raw_text.xlsx**](data_raw_text.xlsx) – Raw survey data with text-based response labels.
- [**data_preprocessed.xlsx**](data_preprocessed.xlsx) – Preprocessed dataset prepared for statistical analyses.

## Data Preparation

Data were collected using SoSci Survey. The raw datasets contain the original survey responses, while the preprocessed dataset was prepared for statistical analyses.
