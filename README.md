This repository contains the research materials, datasets, and analysis scripts for the master's thesis with the title 
Altruism and parochialism in meat-consumption profiles: Conflict intensity and identification with dietary and mammalian ingroup.

## Repository Structure

- **[Materials](Materials/)** – Questionnaires and experimental vignettes used in the study.
- **[Analysis](Analysis/)** – R scripts used for data preprocessing and statistical analyses.
- **[Datasets](Datasets/)** – Datasets used for data preprocessing and statistical analyses.

## Open Science

The files are shared to support transparency and reproducibility of the research.
